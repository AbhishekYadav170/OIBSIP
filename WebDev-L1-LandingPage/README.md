# 🚀 Nexora - Digital Solutions Landing Page

A modern, responsive and professional landing page created as part of the
Oasis Infobyte Web Development and Designing Internship.

---

## 📌 Project Overview

Nexora is a modern digital solutions landing page designed to present
digital services in a clean, professional and user-friendly way.

The website focuses on responsive design, clear navigation, attractive
sections, call-to-action buttons and a simple contact area.

---

## 🎯 Objective

The objective of this project is to create a responsive landing page
with a professional layout and an engaging user experience.

The landing page includes:

- Sticky navigation bar
- Hero section
- Call-to-action buttons
- About section
- Services section
- Features section
- Statistics section
- Call-to-action section
- Contact section
- Footer with social and contact links
- Responsive design for different screen sizes

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Responsive Media Queries
- Google Fonts

---

## ✨ Features

### 1. Sticky Navigation Bar

The website includes a sticky navigation bar with links to:

- Home
- About
- Services
- Features
- Contact

A "Get Started" button is also included.

### 2. Hero Section

The hero section contains:

- Main headline
- Supporting description
- Call-to-action buttons
- Digital growth visual

### 3. About Section

The About section explains the purpose of Nexora and includes
three important points:

- Creative Ideas
- Result Focused
- Reliable Solutions

### 4. Services Section

The website presents four digital services:

- Web Development
- Digital Products
- Growth Strategy
- UI/UX Design

### 5. Features Section

The Features section highlights the benefits of choosing Nexora
and includes project statistics.

### 6. Call-to-Action Section

A dedicated CTA section encourages users to start their project
with Nexora.

### 7. Contact Section

The contact section contains:

- Email
- Phone
- Location
- Contact form

### 8. Footer

The footer contains:

- Company information
- Quick links
- Social links
- Contact information
- Copyright information

---

## 📱 Responsive Design

The website is designed to work across different screen sizes,
including:

- Desktop
- Laptop
- Tablet
- Mobile

CSS media queries are used to adjust the layout and spacing
for smaller screens.
